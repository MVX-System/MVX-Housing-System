# УВЕДОМЛЕНИЕ О ХРАНЕНИИ ДАННЫХ НА УСТРОЙСТВЕ И ИСПОЛЬЗОВАНИИ ФАЙЛОВ COOKIE

**Система MVX — {{controller_name}}**

*Настоящий документ является переводом основной версии на латышском языке. В случае расхождений преимущественную силу имеет версия на латышском языке.*

## 1. Цель Уведомления

Настоящее Уведомление объясняет, каким образом MVX использует технические механизмы хранения данных на устройстве пользователя и в браузере.

MVX может использовать:

- файлы cookie, если они технически необходимы;
- `localStorage`;
- `sessionStorage`;
- PWA Service Worker cache;
- иные предоставляемые браузером механизмы технического хранения, необходимые для работы MVX.

MVX V0.0 не предназначен для использования рекламных, маркетинговых или поведенческих profiling cookies.

## 2. Технически необходимое хранение

MVX может сохранять на устройстве или в браузере информацию, необходимую для:

- аутентификации пользователя и поддержания сессии;
- сохранения выбранных пользователем настроек;
- сохранения языка и настроек интерфейса;
- работы PWA;
- Service Worker cache;
- безопасной работы системы;
- работы push-уведомлений, если пользователь активировал эту функцию.

Такое хранение используется только в объёме, необходимом для соответствующей функции MVX.

## 3. Файлы cookie

MVX V0.0 не предназначен для использования:

- рекламных cookie;
- маркетинговых cookie;
- cookie поведенческой аналитики;
- стороннего рекламного профилирования.

Если cookie технически необходимы для аутентификации, безопасности либо иной функции, запрошенной пользователем, они могут использоваться без отдельного согласия в той мере, в какой это допускается применимым законодательством.

Поэтому MVX V0.0 не требует общего механизма “Accept all cookies”, если не используются технологии, требующие согласия пользователя.

## 4. Local Storage и Session Storage

MVX может использовать `localStorage` и `sessionStorage` браузера для хранения технической информации, необходимой для работы системы.

Такая информация может включать, например:

- настройки пользовательского интерфейса;
- выбор языка;
- техническую информацию, необходимую для сессии или доступа;
- временное состояние приложения.

Эти механизмы не используются для рекламного профилирования.

## 5. PWA и Service Worker

MVX может работать как Progressive Web App (PWA).

PWA Service Worker может сохранять технические ресурсы приложения в cache устройства для:

- ускорения загрузки;
- повышения стабильности работы;
- обеспечения технических функций PWA;
- управления обновлением программных ресурсов.

Cache не предназначен для поведенческого профилирования пользователя.

## 6. Push-уведомления

Push-уведомления являются дополнительной функцией.

Они используются только в том случае, если пользователь разрешил получение уведомлений на уровне устройства или браузера.

Для работы функции может сохраняться техническая информация, включая:

- push endpoint;
- необходимые криптографические ключи;
- языковые или технические настройки;
- информацию о статусе доставки.

Пользователь может отменить разрешение на push-уведомления в настройках устройства или браузера.

## 7. Внешние технические ресурсы

Отдельные функции MVX могут использовать внешние технические ресурсы или сервисы.

При обращении к такому ресурсу поставщику сервиса может быть доступна стандартная техническая информация, например:

- IP-адрес;
- время запроса;
- техническая информация о браузере или устройстве;
- иные стандартные network metadata.

MVX не использует такое техническое взаимодействие для продажи персональных данных или рекламного профилирования.

## 8. Срок хранения

Срок хранения технической информации зависит от конкретного механизма.

Информация может удаляться:

- после завершения сессии;
- по истечении установленного технического срока;
- при выходе пользователя из системы;
- при очистке данных браузера или приложения;
- когда соответствующая техническая запись больше не требуется.

PWA cache может оставаться на устройстве до его обновления, удаления либо очистки данных браузера/PWA.

## 9. Контроль пользователя

Пользователь может с помощью настроек браузера или устройства:

- удалить cookie и локально сохранённые данные;
- очистить PWA cache;
- отменить разрешение на push-уведомления;
- удалить установленное PWA.

Удаление технически необходимых данных может:

- привести к выходу пользователя из MVX;
- сбросить пользовательские настройки;
- временно повлиять на функциональность системы.

## 10. Согласие и будущие изменения

Если в будущем MVX внедрит технологию, использование которой требует согласия пользователя в соответствии с применимым законодательством, такая технология не будет активирована до предоставления пользователю соответствующего выбора.

Настоящее Уведомление в таком случае будет обновлено.
