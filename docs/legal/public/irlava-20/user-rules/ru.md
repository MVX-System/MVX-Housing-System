# ПРАВИЛА ИСПОЛЬЗОВАНИЯ MVX

**Система MVX — DzĪKS “Irlava 20”**

*Настоящий документ является переводом основной версии на латышском языке. В случае расхождений преимущественную силу имеет версия на латышском языке.*

## 1. Цель Правил

Настоящие Правила использования MVX устанавливают основные принципы, которые необходимо соблюдать при использовании системы MVX на объекте **Irlavas iela 20, Rīga**.

MVX представляет собой web/PWA-информационную систему, предназначенную для поддержки процессов управления многоквартирным домом, включая:

- предоставление пользовательского доступа;
- передачу и учёт показаний водомеров;
- получение и распространение объявлений;
- выполнение действий по управлению в соответствии с ролью пользователя и предоставленными ему правами доступа.

Используя MVX, пользователь обязуется соблюдать настоящие Правила и использовать систему только по её назначению.

## 2. Учётная запись пользователя

Учётная запись MVX предназначена для конкретного пользователя и предоставленных ему прав доступа.

Пользователь обязан:

- использовать только свою учётную запись;
- не передавать пароль или иные данные аутентификации другим лицам;
- не создавать условий, при которых другое лицо может использовать учётную запись без разрешения;
- незамедлительно сообщить DzĪKS “Irlava 20”, если имеются основания подозревать несанкционированный доступ к учётной записи;
- при необходимости использовать предусмотренную MVX процедуру восстановления доступа.

Учётная запись не должна передаваться другому лицу, за исключением случаев, прямо предусмотренных порядком предоставления доступа, установленным DzĪKS “Irlava 20”.

## 3. Права доступа и роли пользователей

Функциональность MVX зависит от назначенной пользователю роли и предоставленных прав доступа.

Пользователь вправе получать доступ только к той информации и тем функциям, на которые ему предоставлены соответствующие права.

Запрещается:

- пытаться получить доступ к учётной записи другого пользователя;
- пытаться получить доступ к информации, не предназначенной для данного пользователя;
- обходить или пытаться обойти механизмы разграничения доступа или безопасности MVX;
- использовать технические средства для искусственного расширения своих прав доступа.

DzĪKS “Irlava 20” вправе изменить или отменить права доступа, если изменились связь пользователя с объектом, его обязанности, роль либо иные обстоятельства, являющиеся основанием для предоставления доступа.

## 4. Достоверность информации, вводимой пользователем

Пользователь несёт ответственность за достоверность введённой им информации в той мере, в которой эта информация находится в его распоряжении и под его контролем.

При вводе информации в MVX пользователь должен стремиться к тому, чтобы она была:

- достоверной;
- актуальной;
- достаточно точной;
- соответствующей назначению конкретной функции MVX.

Если пользователь обнаружил ошибку в переданной им информации, ему следует как можно скорее воспользоваться предусмотренной процедурой исправления либо связаться с DzĪKS “Irlava 20”.

## 5. Показания водомеров

При передаче показаний водомера пользователь должен указывать фактическое показание соответствующего прибора с соблюдением установленного MVX периода и порядка передачи показаний.

Пользователь не должен умышленно:

- вводить ложное показание водомера;
- вводить показание другого прибора;
- изменять или искажать информацию с целью повлиять на учёт потребления;
- использовать функции MVX не по назначению.

Если показание было передано ошибочно, пользователь должен сообщить об этом DzĪKS “Irlava 20” либо воспользоваться доступной процедурой исправления.

## 6. Объявления

MVX может использоваться для распространения информации и объявлений, связанных с управлением многоквартирным домом.

Объявления могут быть адресованы:

- всем пользователям;
- определённой группе пользователей;
- пользователям определённой секции дома;
- конкретной квартире;
- конкретному пользователю.

Пользователь должен учитывать, что объявления MVX могут содержать оперативную информацию, связанную с управлением домом.

Push-уведомления являются дополнительной функцией для удобства пользователя. Неполучение push-уведомления само по себе не означает, что информация, опубликованная в MVX, отсутствует в системе.

## 7. Ввод персональных и иных данных

Пользователь должен вводить в MVX только ту информацию, которая необходима для использования конкретной функции либо для целей управления многоквартирным домом.

Без обоснованной необходимости в поля свободного текста, примечания и иные аналогичные поля не следует вводить:

- персональные данные других лиц;
- персональные коды;
- финансовую информацию;
- пароли и иные данные аутентификации;
- сведения о здоровье;
- биометрические данные;
- сведения о религиозных или политических убеждениях;
- иную особо чувствительную информацию либо информацию, не связанную с назначением соответствующей функции MVX.

Если указание информации о конкретном лице объективно необходимо для процесса управления домом, следует указывать только минимально необходимый объём такой информации.

## 8. Безопасность системы

Пользователю запрещается использовать MVX таким образом, который может угрожать безопасности или стабильности системы либо правам других пользователей.

В частности, запрещается:

- без разрешения пытаться проверять или обходить механизмы безопасности;
- распространять вредоносное программное обеспечение;
- создавать автоматизированную нагрузку на систему;
- препятствовать работе MVX;
- использовать ошибки или уязвимости системы в своих интересах либо в интересах другого лица;
- без разрешения копировать, получать или распространять информацию, доступную в системе.

Если пользователь обнаружил возможную проблему безопасности или техническую уязвимость, он должен сообщить об этом DzĪKS “Irlava 20” или технической поддержке MVX и не использовать обнаруженную проблему в своих целях.

## 9. Административные функции

Пользователи, которым предоставлены административные, управленческие или иные расширенные права доступа, вправе использовать их исключительно для выполнения своих обязанностей.

Такие пользователи дополнительно обязаны соблюдать принцип:

> получать доступ только к той информации, которая необходима в конкретной ситуации для выполнения соответствующей рабочей или управленческой задачи.

Административный доступ не предоставляет права просматривать, использовать, копировать или распространять персональные данные в личных целях либо в целях, не связанных с управлением домом.

Отдельные административные действия и действия доступа могут регистрироваться в целях безопасности и аудита.

## 10. Техническая доступность MVX

MVX поддерживается с целью обеспечения максимально возможной стабильности и безопасности работы системы.

Тем не менее временные перерывы в работе могут возникать:

- при проведении технического обслуживания;
- при обновлении программного обеспечения;
- вследствие нарушений работы внешних технических сервисов;
- при аварии или инциденте безопасности;
- по иным технически обоснованным причинам.

Временный технический перерыв сам по себе не означает отказ DzĪKS “Irlava 20” или поставщика технических услуг MVX от исполнения своих обязанностей.

Если определённое действие должно быть выполнено в установленный срок, а MVX технически недоступна, пользователю следует связаться с DzĪKS “Irlava 20” с использованием доступных альтернативных средств связи.

Если имеются обоснованные подозрения относительно:

- несанкционированного доступа;
- использования учётной записи другого пользователя;
- угрозы безопасности системы;
- умышленного ввода ложной информации;

DzĪKS “Irlava 20” вправе временно ограничить использование соответствующей учётной записи или функции в объёме, необходимом для проверки ситуации и защиты системы либо других пользователей.

Такие ограничения применяются соразмерно и только при наличии обоснованной причины.

## 12. Защита персональных данных

Обработка персональных данных в MVX осуществляется в соответствии с отдельным **Уведомлением об обработке персональных данных**.

Информация о файлах cookie и технической информации, сохраняемой на устройстве пользователя, приведена в **Уведомлении о хранении данных на устройстве и использовании файлов cookie**.

Настоящие Правила сами по себе не являются согласием пользователя на обработку персональных данных.

Обработка персональных данных осуществляется на соответствующем правовом основании, указанном в Уведомлении об обработке персональных данных.

## 13. Ответственность за безопасность устройства

Пользователь отвечает за применение разумных мер безопасности на своём устройстве, включая:

- использование блокировки экрана, если устройство может быть доступно другим лицам;
- своевременное обновление операционной системы и браузера;
- неразглашение пароля и иной информации доступа;
- выход из MVX при использовании общего устройства или устройства, доступного другому лицу.

DzĪKS “Irlava 20” и поставщик технических услуг MVX не могут контролировать состояние безопасности личного устройства пользователя.

Программное обеспечение MVX, его структура, элементы дизайна, программный код и иная информация, связанная с разработкой программного обеспечения, охраняются в соответствии с применимыми нормами об интеллектуальной собственности.

Пользователю предоставляется право использования MVX только в объёме, необходимом для использования предусмотренных функций системы.

Пользователю не предоставляется право:

- копировать или распространять программное обеспечение MVX;
- изменять программный код;
- пытаться получить исходный код программы;
