# MVX USER RULES

**MVX System — {{controller_name}}**

*This document is a translation of the Latvian master version. In the event of any discrepancy, the Latvian version shall prevail.*

## 1. Purpose of the Rules

These MVX User Rules establish the basic principles to be followed when using the MVX system at the property **{{property_address}}**.

MVX is a web and PWA information system designed to support residential property management processes, including:

- providing user access;
- submitting and recording water meter readings;
- receiving and distributing announcements;
- carrying out management activities according to the user’s role and assigned access rights.

By using MVX, the user undertakes to comply with these Rules and to use the system only for its intended purposes.

## 2. User Account

An MVX user account is intended for a specific user and the access rights assigned to that user.

The user must:

- use only their own user account;
- not disclose their password or other authentication information to other persons;
- not create circumstances in which another person can use the account without authorisation;
- immediately inform {{controller_name}} if unauthorised access to the account is suspected;
- use the MVX account recovery procedure where necessary.

A user account must not be transferred to another person, except where this is expressly permitted under the access procedure established by {{controller_name}}.

## 3. Access Rights and User Roles

MVX functionality depends on the role and access rights assigned to the user.

A user may access only the information and functions for which access has been granted.

It is prohibited to:

- attempt to access another user’s account;
- attempt to access information not intended for the user;
- bypass or attempt to bypass MVX access-control or security mechanisms;
- use technical means to artificially extend the user’s access rights.

{{controller_name}} may change or revoke access rights where the user’s relationship with the property, duties, role or other circumstances justifying access have changed.

## 4. Accuracy of Information Entered by the User

The user is responsible for the accuracy of information entered by them to the extent that such information is within their knowledge and control.

When entering information into MVX, the user should make reasonable efforts to ensure that it is:

- truthful;
- up to date;
- sufficiently accurate;
- relevant to the purpose of the particular MVX function.

If the user discovers an error in information they have submitted, they should use the available correction procedure or contact {{controller_name}} as soon as reasonably possible.

## 5. Water Meter Readings

When submitting a water meter reading, the user must provide the actual reading of the relevant meter in accordance with the submission period and procedure established in MVX.

The user must not knowingly:

- submit a false meter reading;
- submit a reading from another meter;
- alter or distort information for the purpose of affecting consumption accounting;
- use MVX functions for purposes other than those for which they were designed.

If a reading has been submitted incorrectly, the user must inform {{controller_name}} or use the available correction procedure.

## 6. Announcements

MVX may be used to distribute information and announcements related to residential property management.

Announcements may be addressed to:

- all users;
- a particular user group;
- users of a particular section of the building;
- a particular apartment;
- a particular user.

Users should be aware that announcements in MVX may contain operational information relating to the management of the property.

Push notifications are an additional convenience feature. Failure to receive a push notification does not in itself mean that information published in MVX is unavailable in the system.

## 7. Entry of Personal Data and Other Information

Users should enter into MVX only information that is necessary for the use of a particular function or for residential property management purposes.

Unless objectively necessary, free-text fields, notes and similar fields must not contain:

- personal data relating to other persons;
- personal identification numbers;
- financial information;
- passwords or other authentication information;
- health information;
- biometric data;
- information concerning religious or political beliefs;
- other particularly sensitive information or information unrelated to the relevant MVX function.

Where information relating to a particular person is objectively necessary for a residential property management process, only the minimum amount of information necessary should be provided.

## 8. System Security

Users must not use MVX in a manner that may compromise the security or stability of the system or the rights of other users.

In particular, it is prohibited to:

- attempt to test or bypass security mechanisms without authorisation;
- distribute malicious software;
- overload the system through automated activity;
- interfere with the operation of MVX;
- exploit system errors or vulnerabilities for personal benefit or for the benefit of another person;
- copy, obtain or distribute information available in the system without authorisation.

If a user becomes aware of a possible security issue or technical vulnerability, they should notify {{controller_name}} or MVX technical support and must not exploit the issue.

## 9. Administrative Functions

Users who have been granted administrative, management or other extended access rights may use those rights only for the performance of their duties.

Such users must additionally follow the principle:

> access only the information that is necessary in the particular circumstances to perform the relevant work or management task.

Administrative access does not give a user the right to view, use, copy or disclose personal data for personal purposes or for purposes unrelated to residential property management.

Certain administrative and access activities may be logged for security and audit purposes.

## 10. Technical Availability of MVX

MVX is maintained with the aim of providing the most stable and secure operation reasonably possible.

Temporary interruptions may nevertheless occur:

- during technical maintenance;
- during software updates;
- due to disruption of external technical services;
- in the event of an emergency or security incident;
- for other technically justified reasons.

A temporary technical interruption does not in itself mean that {{controller_name}} or the MVX technical service provider has refused to perform its obligations.

If a particular action must be completed within a specified period and MVX is technically unavailable, the user should contact {{controller_name}} using the available alternative communication channels.

## 11. Unauthorised or Improper Use

Where there are reasonable grounds to suspect:

- unauthorised access;
- use of another user’s account;
- a threat to system security;
- intentional submission of false information;
- use of MVX contrary to these Rules;

{{controller_name}} may temporarily restrict use of the relevant account or function to the extent necessary to investigate the situation and protect the system or other users.

Such restrictions are applied proportionately and only where justified.

## 12. Personal Data Protection

Personal data processing within MVX is carried out in accordance with the separate **Personal Data Processing Notice**.

Information about cookies and technical information stored on the user’s device is provided in the **Device Storage and Cookie Notice**.

These User Rules do not themselves constitute user consent to the processing of personal data.

Personal data are processed on the relevant legal basis described in the Personal Data Processing Notice.

## 13. Responsibility for Device Security

Users are responsible for taking reasonable security measures on their own devices, including:

- using a screen lock where the device may be accessible to other persons;
- keeping the operating system and browser up to date;
- not disclosing passwords or other access information;
- signing out of MVX when using a shared device or a device accessible to another person.

{{controller_name}} and the MVX technical service provider cannot control the security condition of a user’s personal device.

## 14. Intellectual Property

The MVX software, its structure, design elements, program code and other information related to software development are protected under applicable intellectual property rules.

The user is granted only such right to use MVX as is necessary to use the intended functions of the system.

The user is not granted the right to:

- copy or distribute MVX software;
- modify the program code;
- attempt to obtain the program source code;
- use MVX or parts of it to create another software product;

except where such rights arise directly from applicable law or a separate written agreement.

## 15. Pilot Project Status

MVX V0.0 is used at **{{property_address}}** as a pilot project.

During the pilot project, MVX functionality, the user interface and technical solutions may be improved or changed.

Such changes must not reduce compliance with applicable personal data protection or system security requirements.

Users will be informed in a reasonable manner of material changes affecting their rights or the manner in which the system is used.

## 16. Changes to the Rules

These Rules may be updated if there are changes to:

- MVX functionality;
- residential property management processes;
- security requirements;
- applicable law;
- other material circumstances concerning the use of the system.

Each published version of the Rules is identified by a version number and effective date.

Where changes materially affect user rights or obligations, users will be informed through MVX or another communication method used by {{controller_name}}.
